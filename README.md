# ESCAPE-FROM-CIN

- A ideia inicial do projeto é desenvolver um jogo no estilo Endless Runner, onde o personagem
  precisa  coletar 3 letras: C, I, N para conseguir resolver o puzzle final e escapar.

- O jogo terá 3 tipos de coletáveis: Vida, Velocidade e uma das letras para resolver o puzzle final.

- A estrutura será baseada nos conceitos de programação orientada a objetos em python
  junto com a utilização da biblioteca pygame.
